Python Case Studies Worked Solutions

This package contains a Word report with ten worked Python case studies selected from the supplied difficulty-classification PDF:

- **Easy:** Progressive Electricity Billing (2), Password Policy Validation Engine (29), Attendance Recovery Computation (12), Progressive Water Tariff Analysis (25)
- **Medium:** Warehouse Inventory Reconciliation (14), Student Timetable Conflict Detection (23), Repeated Transaction Detection (28), Student Academic Risk Classification (66)
- **Hard:** University Scholarship Allocation (1), University Hostel Room Allocation (89)

## What's included

For each case, the report gives the problem assumptions, a high-level algorithm, a text flowchart, pseudocode, a Python 3 implementation, and expected test results.

## How to use

1. Open `Python_Case_Studies_Worked_Solutions.docx` in Word or another DOCX-compatible editor.
2. Copy the code block for a case into a `.py` file or Python 3 interpreter.
3. Run the code and compare its output with the expected results in the report.
4. If your course requires IDE screenshots, capture them from your own Python environment after running each example.

## Assumptions

The source PDF lists case titles and difficulty levels but does not specify detailed rules. The report therefore states reasonable rules for each example. Update thresholds, tariffs, or allocation rules if your instructor provides different specifications. Currency examples use rupees.

The scholarship and hostel examples use explicitly defined greedy allocation rules for deterministic results; they are not global optimization algorithms. The report provides expected console output, not IDE screenshots.
